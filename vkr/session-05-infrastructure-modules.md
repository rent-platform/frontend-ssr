## 2. Каталог пользовательских перехватчиков состояния (5 перехватчиков)

Каталог общих перехватчиков содержит пять переиспользуемых перехватчиков состояния, инкапсулирующих типовые паттерны управления данными и взаимодействия с пользователем. Каждый перехватчик является чистым модулем без побочных эффектов (за исключением подписок на события браузера) и экспортируется через индексный файл (482 байт).

### 2.1. Перехватчик постраничной навигации (2 790 байт, 105 строк)

Перехватчик принимает массив элементов произвольного типа и объект настроек (начальная страница, количество элементов на странице, варианты количества). Возвращает объект с 14 свойствами и методами:

- текущая страница, количество элементов на странице и варианты выбора количества;
- общее количество элементов и общее число страниц;
- массив элементов текущей страницы (вычисляемый с мемоизацией);
- начальный и конечный индексы текущей страницы;
- функции навигации: переход к заданной странице (с ограничением допустимого диапазона), переход к следующей, предыдущей, первой и последней страницам;
- функция установки количества элементов на странице (при изменении автоматически сбрасывает страницу на первую);
- функция генерации номеров страниц для отображения (с поддержкой многоточия при большом числе страниц, максимум 5 видимых номеров).

Перехватчик покрыт 17 модульными тестами, проверяющими все граничные условия.

### 2.2. Перехватчик сортировки (2 058 байт, 74 строки)

Перехватчик принимает массив элементов, объект функций доступа к полям (по именованным ключам) и необязательную начальную сортировку. Возвращает отсортированный массив, текущий ключ и направление сортировки, функцию переключения направления и функцию сброса.

Алгоритм сортировки поддерживает строковые значения (с использованием русскоязычной локали для корректного упорядочивания кириллических символов), числовые и логические значения. Пустые значения всегда помещаются в конец массива. Исходный массив не модифицируется — создаётся новая копия, что обеспечивает неизменяемость данных.

Перехватчик покрыт 10 модульными тестами.

### 2.3. Перехватчик бесконечной прокрутки (1 221 байт, 47 строк)

Перехватчик принимает четыре параметра: флаг наличия дополнительных данных, функцию загрузки следующей порции, флаг приостановки и отступ области наблюдения (по умолчанию 360 пикселей). Возвращает ссылку на элемент-наблюдатель для размещения в конце списка.

Перехватчик использует программный интерфейс наблюдателя пересечений для отслеживания видимости элемента-наблюдателя. При попадании элемента в расширенную область видимости вызывается функция загрузки. При размонтировании компонента или изменении зависимостей наблюдатель автоматически отключается.

### 2.4. Перехватчик ловушки фокуса (1 715 байт, 59 строк)

Перехватчик принимает флаг активности и возвращает ссылку на элемент-контейнер. При активации:

- собирает все фокусируемые элементы внутри контейнера (ссылки, кнопки, текстовые поля, элементы ввода, выпадающие списки, элементы с порядком фокусировки), исключая элементы, скрытые от средств доступности;
- при первом нажатии клавиши табуляции на последнем элементе перемещает фокус на первый, при обратной табуляции на первом — на последний;
- при монтировании автоматически устанавливает фокус на первый фокусируемый элемент, если фокус находится за пределами контейнера.

### 2.5. Перехватчик отслеживания прокрутки (707 байт, 24 строки)

Перехватчик принимает пороговое значение вертикальной прокрутки (по умолчанию 600 пикселей). Возвращает флаг видимости (истина, если прокрутка превышает порог) и функцию плавной прокрутки к началу страницы. Подписка на событие прокрутки выполнена с флагом пассивного обработчика для оптимизации производительности.

Каталог тестов перехватчиков содержит 2 файла: тесты постраничной навигации (17 тестов) и тесты сортировки (10 тестов).

### 3.3. Централизованная карта маршрутов (1 200 байт, 40 строк)

Файл определяет единый объект, содержащий все маршруты приложения. Статические маршруты (20 штук) определены как строковые константы: главная страница, каталог, авторизация, регистрация, поиск, чат, создание объявления, избранное, гостевая страница, уведомления, личный кабинет, отзывы, настройки, цены и тарифы, для бизнеса, центр помощи, безопасность, условия, конфиденциальность, о компании, карьера, контакты, файлы.

Динамические маршруты (5 штук) определены как функции, принимающие идентификатор и возвращающие сформированный путь: просмотр объявления, редактирование объявления, публичный профиль пользователя, детали сделки (с опциональным идентификатором — при его отсутствии открывается демонстрационный режим), страница оплаты (с опциональным идентификатором сделки).

При интеграции с серверной маршрутизацией необходимо обновить только этот файл — все компоненты, использующие маршруты, автоматически получат новые пути.

### 3.4. Константы анимации (192 байт, 6 строк)

Файл определяет кривую ослабления анимации, используемую библиотекой декларативных анимаций во всех функциональных модулях. Кривая представляет кубическую аппроксимацию пружинного ослабления (значения: 0.23, 1, 0.32, 1).

### 3.5. Файлы реэкспорта (2 файла)

Файл реэкспорта контекста темы (127 байт) переэкспортирует провайдер и перехватчик темы из каталога контекстов, обеспечивая сокращённый путь импорта. Файл реэкспорта перехватчика ловушки фокуса (57 байт) выполняет аналогичную функцию для каталога перехватчиков.

Каталог тестов утилит содержит 2 файла: тесты форматирования (38 тестов) и тесты плюрализации (15 тестов).

## 4. Каталог типов представления (3 файла)

Каталог типов содержит определения типов данных, специфичных для слоя представления и не имеющих прямого соответствия в бизнес-слое. Все типы экспортируются через индексный файл (166 байт).

### 4.1. Типы статусов сделки (1 256 байт, 36 строк)

Файл определяет тип-объединение из 7 статусов сделки аренды: «ожидает подтверждения», «подтверждена», «ожидает оплаты», «активна», «завершена», «отклонена», «отменена». Данный тип расширяет серверный тип сделки (6 статусов) дополнительным статусом «ожидает оплаты», который необходим для корректного отображения жизненного цикла сделки в пользовательском интерфейсе. При добавлении данного статуса на серверной стороне тип будет заменён реэкспортом из бизнес-слоя.

Файл также содержит два справочника соответствия: полные текстовые метки статусов на русском языке (для развёрнутого отображения) и сокращённые метки (для компактных числовых индикаторов).

### 4.2. Типы статусов объявления (339 байт, 11 строк)

Файл определяет справочник текстовых меток для 5 статусов объявления: «Активно», «На модерации», «Черновик», «В архиве», «Отклонено». Тип статуса импортируется из бизнес-слоя, что обеспечивает типобезопасное соответствие между серверными и клиентскими статусами. Справочник используется в модулях личного кабинета, панели администратора и панели модератора для единообразного отображения статусов объявлений.

## 7. Каталог макетов страниц (4 макета, 26 файлов)

Макеты страниц определяют общую визуальную структуру, переиспользуемую несколькими страничными маршрутами. Каждый макет содержит компонент-обёртку, файл стилей и, при необходимости, вложенные компоненты.
